# 方法与关键结论

> English: [method_EN.md](method_EN.md)

## 任务

影棚 = 固定 Blender 场景（`scene/stage.blend`）：8 灯槽（`light_01`-`light_08`）、`product`
集合、唯一相机。布光方案 = **72 维配置**（8 槽 × 9 参数：位置 3 / 瞄准 2 / 滚转 1 / 能量 1 /
尺寸 2，tanh 空间）。任务实例 = (产品, 机位)，双机位 = 正面 / 右上 45° 高位，各一套配置。

## 推理管线

```
新品 ─▶ 嵌入（冻结 ResNet18，4 张辅助渲染）─▶ NN 继承：最近邻借一套已调好的 72 维当起点
     ─▶ 策略 2 步精修：step1 出动作→渲预览图→嵌入进 obs；step2 出终值 72 维→渲正式图
     ─▶ best-of-16：同 obs 采样 16 候选 → RM 裁决 → winner 上场景
```

观测 2640 维 = [static 2056（产品嵌入 2052 + 机位/抖动 4）｜当前配置 72｜预览嵌入 512]；
奖励 = RM 对终帧的 z 分；部署另有 do-no-harm 门控（改造幅度 ≤ τ 则保留继承光）。

## RM（人标偏好模型）

DINOv2-L/14 冻结骨干 + 小型打分头（1024→128→1）。训练数据 = 人对渲染图对的盲标偏好，
成对 hinge loss，纯人标配方；z 分 =（原始分 − 训练集均值）/ 标准差。
部署中 RM 只做**候选裁决**，不直接充当输出。

## 训练配方（终版策略）

| 项 | 值 |
|---|---|
| 引擎 | RLOO：同起点 K=10 次重放，advantage = R_i − mean(R_≠i)（精确 LOO 基线，**无 critic**） |
| 起点 | 同管线前代策略热启动（含自学 σ） |
| 奖励 | 同代 RM 的 z 分，**仅终端**（2 步 episode，r1 ≡ 0） |
| 附加项 | 无（零熵奖励 / 零锚 / 零排斥；只留仪表：min-grp-std、塌缩预警、分段 ckpt） |
| 起点机制 | 46 个种子产品的 NN 继承 + 扰动（leave-self-out） |
| 刹车 | clip 0.2 + target-KL 0.2 早停 + 梯度裁剪 0.5 |
| 预算 | 300k 环境步 = 326 轮（46 起点 × K10 × 2 步 = 920 步/轮），双 worker 并行 |

关键设计：无 critic（2 步终端奖励下 V(s) 无意义，且 off-policy 的 actor 会钻 Q 的外推误差），
靠刹车限速 + σ 自学退火在 RM 的精细地貌上慢磨（约 +0.1z / 40-60 轮）。

## 泛化性：什么迁移、什么不迁移

**迁移成立的部分（精修策略对未见产品有效）**

| 池 | Δ(策略 − 噪继承基线) | 胜格 |
|---|---|---|
| 种子产品 32 机位 | **+1.674** | 31/32 |
| 留出 6 产品 12 机位（从未训练/标注） | **+0.793** | 12/12 |
| 新品 85 机位（训练时无种子） | **+1.200** | 79/85 |

人眼盲评（新品池 85 对，双盲）：终版 **0.472** vs 历代最强基线 0.528（p≈0.90 平局），
其中 **58% 的对子人眼不可区分**。即：精修行为在未见产品上稳定优于"继承即交付"的基线，
并与最强基线在审美上打平。

**不迁移的部分（产品特异审美不可预测）**

46 个种子（92 机位）的灯光方差 **94.8% 是产品特异的**（跨产品共享成分 4.4-5.2%）。
从产品观测（嵌入双空间 / 逐灯贡献图，线性与非线性预测器）预测产品特异残差，
严格留一协议下 **R² ≤ 0，46 个产品 0 个为正**——产品特异残差是**审美任意的，不是物理决定的**：
两个光照响应完全相同的产品，人可以给出完全不同的灯。因此新品质量靠**覆盖**（人工调一个存一个
种子），而不是靠从观测推断。

**配方级可复现**：同配方（同代 RM 当奖励 + 冠军亲本热启动 + 零药）在新底盘上重新训练，
三池 RM z 全部达到或超过原冠军锚点（+1.582/+0.832/+1.137 vs +1.282/+0.428/+1.185），
新品人尺打平——冠军血脉可由"一个 RM ckpt + 一条训练命令"再衍。

## 边界

- 人尺结论来自**单一专家标注者**（部署服务对象即该操作者）
- 全部数字出自单一白底电商品类带，外推未测
- 策略跨产品多样性 ≈ 人工的 0.5×（该配方的固有水位，非本管线验收指标，如实披露）
- 跨 RM 版本的 z 分不可直接比较（各自以本代训练集为基准）
